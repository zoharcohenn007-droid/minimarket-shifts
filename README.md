# שעון נוכחות למיני מרקט

## 🔗 כתובת התוכנה
**https://zoharcohenn007-droid.github.io/minimarket-shifts/**

תוכנה לטאבלט בחנות: כניסה ויציאה ממשמרת עם קוד אישי, אישור חובה של הנחיות מכירת אלכוהול ומוצרי עישון, שלט אזהרה קבוע עם תאריך גיל 18, ניהול עובדים ומסמכים, סיכום שעות חודשי וסידור עבודה עם שליחה בוואטסאפ.

## חשבונות בענן (מגרסה 2.0)
- כל בעל עסק נרשם עם **מייל וסיסמה** ("הרשמה – עסק חדש"). הנתונים של כל עסק נשמרים ב-Google Firebase, באזור **תל אביב (me-west1)**.
- כל עסק רואה **רק** את הנתונים שלו. כללי ההרשאה נמצאים ב-`firebase/firestore.rules` וב-`firebase/storage.rules`.
- אפשר להתחבר מכמה מכשירים (טאבלט, טלפון, מחשב), והכל מסתנכרן בזמן אמת.
- **בלי אינטרנט** התוכנה ממשיכה לעבוד: כניסות ויציאות ממשמרות נשמרות בטאבלט ועולות לענן כשהחיבור חוזר. העלאת מסמכים דורשת חיבור.
- **גיבוי:** Firestore מגבה את מסד הנתונים כל יום ושומר כל גיבוי 7 ימים. בנוסף, ⚙️ הגדרות ← "הורדת גיבוי לקובץ".
- **נתונים מגרסה קודמת:** בכניסה הראשונה התוכנה מציעה להעביר לחשבון את הנתונים שכבר שמורים בטאבלט, כולל המסמכים.

## התקנה על הטאבלט
1. פותחים בדפדפן **Chrome** את כתובת התוכנה.
2. בתפריט (⋮) בוחרים **"הוספה למסך הבית"** או **"התקנת אפליקציה"**.
3. פותחים את התוכנה מהאייקון ונכנסים עם המייל והסיסמה של העסק. הטאבלט נשאר מחובר.
4. בעסק חדש ממלאים את אשף ההקמה, ואחר כך לוחצים **👥 עובדים** ומוסיפים עובדים.

## שימוש יומיומי
- **עובד:** מקליד את הקוד האישי שלו, מאשר את ההנחיות ונכנס למשמרת. ב-**👤 האזור האישי** הוא רואה את המשמרות שלו ואת הסידור, ומגיש זמינות לשבוע הבא.
- **מנהל:** כלי הניהול מבקשים קוד מנהל. הם ננעלים כשחוזרים למסך הבית, או אחרי 5 דקות בלי שימוש.
- **התנתקות** (⚙️ הגדרות) מוחקת מהמכשיר את כל הנתונים של העסק. הנתונים נשארים בענן.

## חשוב לדעת
- התראת התקציב ב-Google **רק שולחת מייל** ולא עוצרת את השירות.
- **נוסח ההנחיות** הוא הצעה ואינו ייעוץ משפטי. אפשר לערוך אותו ב: ⚙️ הגדרות.
- אחסון פרטים וצילומי תעודות של עובדים כפוף ל**חוק הגנת הפרטיות**. אם עסקים אחרים משתמשים בתוכנה, צריך מדיניות פרטיות ותנאי שימוש.
