# שעון נוכחות למיני מרקט

## 🔗 כתובת התוכנה
**https://zoharcohenn007-droid.github.io/minimarket-shifts/**

תוכנה לטאבלט בחנות: כניסה ויציאה ממשמרת עם קוד אישי, אישור חובה של הנחיות מכירת אלכוהול ומוצרי עישון, שלט אזהרה קבוע עם תאריך גיל 18, ניהול עובדים ומסמכים, סיכום שעות חודשי וסידור עבודה עם שליחה בוואטסאפ.

## התקנה על הטאבלט
1. פותחים בדפדפן **Chrome** את כתובת התוכנה.
2. בתפריט של Chrome (שלוש הנקודות) בוחרים **"הוספה למסך הבית"** או **"התקנת אפליקציה"**.
3. פותחים את התוכנה מהאייקון שנוצר. היא תיפתח במסך מלא.
4. בפתיחה הראשונה ממלאים את אשף הקמת העסק בארבעה שלבים: פרטי העסק, שעות פעילות, משמרות וקוד מנהל.
5. לוחצים על **👥 עובדים** בסרגל הכלים ומוסיפים את העובדים.

## שימוש יומיומי
- **עובד:** מקליד את הקוד שלו, קורא את ההנחיות, מסמן את שני האישורים ונכנס למשמרת. ביציאה מקליד את הקוד שוב.
- **מנהל:** כל כלי בסרגל הכלים מבקש קוד מנהל. הניהול ננעל כשחוזרים למסך הבית, או אחרי 5 דקות בלי שימוש.

## חשוב לדעת
- **הנתונים נשמרים רק על הטאבלט.** כדאי להוריד גיבוי פעם בשבוע: ⚙️ הגדרות ← "הורדת גיבוי", ולשמור את הקובץ גם במקום אחר (מייל, Google Drive).
- **לא מנקים את נתוני הדפדפן** של התוכנה, כי זה מוחק את כל המידע.
- התוכנה עובדת גם **בלי אינטרנט**. שליחת מייל ווואטסאפ צריכות חיבור.
- **שליחת הסיכום החודשי אוטומטית** דורשת הגדרה חד-פעמית של EmailJS. ההוראות נמצאות ב: ⚙️ הגדרות.
- **נוסח ההנחיות** הוא הצעה ואינו ייעוץ משפטי. אפשר לערוך אותו ב: ⚙️ הגדרות ← "הנחיות מכירה".

## עדכונים
כשהתוכנה מתעדכנת בשרת, הטאבלט מקבל את הגרסה החדשה בפתיחה הבאה, כל עוד יש אינטרנט. הנתונים נשמרים, בתנאי שכתובת התוכנה לא משתנה.
